# Python Expense Tracker

A beginner-friendly Python project to record and manage daily expenses.

## Features

- Add expenses with a name, category, amount, and date
- View all recorded expenses
- Calculate total expenses
- Generate a monthly spending report
- View expenses grouped by category
- Save expenses permanently using JSON
- Validate amounts and handle invalid input

## Technologies Used

- Python
- JSON file handling
- Git and GitHub

## Requirements

- Python 3 installed
- VS Code or another Python editor

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python expense_tracker.py

## Example

Add a notebook expense:

- Name: Notebook
- Category: Books
- Amount: 50

The program saves the expense and includes it in the reports.
